# Resume-ready project entry

**Finance Operations Analytics & Local AI Finance Analyst**  
*Python, PostgreSQL, SQLAlchemy, Pandas, Excel Automation, Streamlit, Ollama (Qwen 2.5 3B)*

- Built a Python-to-PostgreSQL pipeline for synthetic finance operations data covering customers, vendors, sales, receivables, expenses, payables, budgets, and bank transactions.
- Implemented data-quality checks for missing transaction links, invalid payment amounts, empty datasets, and duplicate budget periods, with safeguards against accidental pipeline reruns.
- Automated a multi-sheet Excel reporting workbook from six finance reporting views and developed a local natural-language-to-SQL interface with SQL allow-list validation and read-only query execution.
